# Contributing to ByeBlocked

Thanks for taking the time to contribute! This is a solo-maintained project, so response times may vary, but every bit of help is appreciated.

## Found a bug?

Open a [Bug Report](https://github.com/8ug8ird/ByeBlocked/issues/new?template=bug_report.yml). Try to include:

- The ByeBlocked and BetterDiscord versions you're using
- Steps to reproduce the issue
- Any errors from the DevTools console (Ctrl+Shift+I)

## Have an idea or suggestion?

Open a [Feature Request](https://github.com/8ug8ird/ByeBlocked/issues/new?template=feature_request.yml). Half-formed ideas are welcome too, it's easier to discuss and refine a suggestion than to guess what would be useful.

## Want to submit code?

1. Fork the repository
2. Create a branch for your change (`git checkout -b fix/short-description`)
3. Make your changes
4. Validate the file with `node --check ByeBlocked.plugin.js` before opening the PR
5. Open a pull request describing what you changed and why

Since I maintain this project alone, please keep PRs focused on a single change when possible, it makes review much faster. For larger changes, it's a good idea to open an issue first to discuss the approach before investing time in the implementation.

## Code style

Try to match the existing code style and structure of the plugin as closely as possible. If you're unsure about something, feel free to ask in an issue before submitting a PR.
